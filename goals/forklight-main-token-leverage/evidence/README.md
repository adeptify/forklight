# Evidence

This directory indexes compact evidence needed to verify the Goal. It is not a second progress
log and must not copy raw ForkLight events.

Expected evidence:

- `m1-cli-api-gap-audit.md` — final M1 requirement matrix, gap audit and boundary result.
- `data-retention-report.json` — verified backups, eligibility and referential-closure rules,
  applied cleanup, current attention closure and integrity checks.
- `coding-delegation-run.md` — one representative Coding journey.
- `noncoding-delegation-run.md` — one representative non-Coding journey.
- `main-token-pairs.json` — reviewed same-scope, same-acceptance paired evidence.
- `clean-clone-run.md` — final unfamiliar-developer journey.
- final Hub screenshots and Impeccable verdict after CLI/API graduation.

Each entry must point to durable machine evidence or a reviewed artifact. Missing evidence is
reported as unavailable; it is never inferred.
