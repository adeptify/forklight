## Ready-to-run unfamiliar-operator handoff

This is the frozen observation protocol. It prevents later coaching or favorable reinterpretation;
it is not a completed result template.

### Eligible subject and environment

- The operator has not previously used ForkLight, reviewed this Goal or seen the expected answers.
- Use a clean macOS user, disposable VM or clean Mac. Creating that environment remains a separate
  system-level action; it is not performed implicitly by this Goal.
- Give the operator only `/Users/Shared/ForkLight-Clean-Run.65178a8a` and its packaged runbook.
  Do not provide source checkout, internal evidence, database access or hand-written settings.

### Observer boundary

- The observer may say only: “请从这份文件夹和其中的说明开始，完成一次真实任务交付；遇到
  问题请按你自己的理解处理并说出你在找什么。”
- Do not name the next button, explain Goal/Plan/Task, interpret status, suggest an answer, repair
  configuration or complete an action for the operator.
- Record every question, observer reply and intervention verbatim. Any answer beyond the frozen
  opening sentence is an intervention; database/settings/source editing is a hard failure.
- Do not restart with a second operator or repeat the journey after a poor result. A failure returns
  to the exact observed Work Item.

### Clock and checkpoint record

Start the 30-minute clock before the operator opens the runbook. Record canonical local timestamps
for: start, setup ready, first Task confirmed, first independently verified Candidate, Main decision,
safe Integration, Hub/Main restart and end. Thirty minutes is an acceptance target, never a process
kill timeout.

For each checkpoint record only privacy-safe facts: elapsed time, visible user action, visible
result, whether help was requested, and any intervention. Never record credentials, Keychain
content, private logs, usernames, home paths or unrelated screen content.

### Uncoached comprehension gate

After the final Hub is visible, ask the following without explaining vocabulary. Give ten seconds
for the operator to answer in their own words:

1. 你正在完成什么？
2. 现在发生了什么？
3. 现在需要你做决定吗？
4. 已经保留了哪些工作？
5. 接下来会发生什么？

Record the answers verbatim and assess meaning, not exact wording. A field being present on screen
is not proof that the operator understood it.

### Visual and restart observation

- Capture privacy-safe desktop and mobile-width views of current work, History, Decision Center,
  one setup blocker, running, retained partial/failure and delivered states.
- Observe keyboard focus, visible focus, contrast, reduced motion and the mobile Back path.
- Restart Hub and Main once. Confirm the selected work and semantic truth return without a duplicate
  Worker Attempt or Integration.

### Verdict

Pass only if one eligible operator completes setup, a real Task, Main review and safe Integration
within 30 minutes, uses no forbidden intervention, answers all five questions correctly in their
own words, and the bounded visual/restart checks pass. Otherwise record the first concrete failure
and return it to the responsible accepted Work Item. Do not average, coach or replay it away.
