# M5-C — Unfamiliar-developer and visual graduation

## User result

A developer who has not used ForkLight completes setup, one real Task, Main review and safe
Integration in 30 minutes without database inspection or manual configuration-file editing, and can
explain the current work in plain language.

## `depends_on`

- M5-B accepted and integrated.
- One frozen clean bundle from M5-A3.
- A genuinely clean macOS user, disposable VM or clean Mac, plus a willing unfamiliar operator.

## Procedure and evidence

- Use the frozen installed package and normal product surfaces only. Do not fall back to source,
  `npm link`, database editing or hand-written settings.
- Record start/end, setup completion, first verified Candidate and final Integration times. Thirty
  minutes is the exit target, not a process-kill timeout.
- Ask without coaching: What are you trying to finish? What is happening now? Do you need to decide?
  What work is retained? What happens next?
- Exercise desktop and mobile widths for Now, History, Decision Center, setup blocker, running,
  partial/failure and delivered states. Capture only privacy-safe screenshots.
- Restart Hub/Main once and prove selection/truth recovery without duplicate Worker or Integration.
- Record every developer intervention. A question that only a developer can answer is a product
  comprehension gap, not a passed field-presence check.

## Allowed paths

- `goals/forklight-main-led-execution/evidence/clean-clone-run.md`
- final privacy-safe screenshot/QA evidence under the same Goal evidence directory
- `progress.md`, `decisions.md`, `evidence/README.md` updated serially by Main
- relevant accepted M5-A/B spec only if observed evidence proves its contract must change

## Forbidden paths and non-goals

- Product-code changes hidden inside the observation, database/settings edits, coached answers,
  synthetic timing, repeated favorable operator reruns, credential capture, GoalBoard writes,
  commit or push.
- Creating/deleting a macOS account or VM without the separate explicit system-level authorization
  required at execution time.

## Acceptance

- Technical clean install and one real full delivery remain valid on the frozen package.
- The unfamiliar operator completes the full journey within 30 minutes and needs no forbidden
  intervention.
- The 10-second comprehension questions are answered correctly in the operator's own words.
- Desktop/mobile, keyboard, focus, contrast, reduced motion, refresh preservation and core states
  pass bounded visual QA.
- Any blocker returns to the exact accepted Work Item; it does not trigger an unrelated redesign,
  automatic retry, model switch or favorable replay.
- `npm run check`, `doctor --json`, `health --json`, Goal/board/stats reads and `git diff --check`
  pass at the M5 boundary before Main graduates the Goal.

## Handoff and workspace disposition

The final packet contains the frozen build, anonymized environment, actual timing, intervention
record, comprehension answers, Task/review/Integration evidence, screenshots, accessibility result,
